# Habbit Mobile
Aqui está presente todo o código do aplicativo mobile do Habbit, desenvolvido em React Native com Expo.

## Instalação
Para instalar as dependências do projeto, execute o seguinte comando:
```bash
pnpm install
```

## Executando o aplicativo
Para iniciar o aplicativo, você pode usar o comando:
```bash
pnpm start
```

Você pode escolher entre iniciar o aplicativo em no Expo Go ou no navegador web.

### Testes
Para rodar os testes do aplicativo, utilize o comando:
```bash
pnpm test
```

### Storybook
Para iniciar o Storybook, utilize o comando:
```bash
pnpm storybook
```
